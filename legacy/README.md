# Historical files — not the corrected paired result

These files are kept for research provenance only. Do **not** treat the two old spreadsheets as a controlled order-only A/B comparison.

- `exp2_code.ipynb` is the original progressive experiment from the initial GitHub repository.
- `pipeline_stepwise_progressive_AO.xlsx` evaluates 15 A–O pipelines in the original progressive branch.
- `pipeline_stepwise_progressive_AO_MVfirst.xlsx` contains early-stage MV-first outputs for only five A–E pipelines.

The branches differed in stage coverage and feature representation. The historical comparison therefore did not isolate operator order. The corrected, controlled evaluation is at repository root (`step_order.ipynb`, `reproduce.py`, and `results/`).
